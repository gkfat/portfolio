## Overview

完整的腳踏車循環租借系統，包含後台、站點平台、客戶端與 Line Liff。

## Business Challenge

循環租借需要後台、站點與客戶端協同運作，才能管理車輛、營業時間、權限與銷售。

## Solution

以後台、Server、站點平台與客戶端組成完整系統，由 Server 提供 API 與 RBAC 權限，後台管理營運設定，站點平台負責現場銷售與通知。

## Key Features

- 後台
  - 權限設定、營業時間管理、系統設定、車輛管理
  - 主控板效能優化
  - 無限庫存商品功能
- Server
  - 基於 RBAC 架構的權限功能
  - 營業時間、系統設定與車輛管理
- 站點平台
  - 推播通知與 FCM 註冊流程
  - 商品報表
  - 銷售無限庫存商品
