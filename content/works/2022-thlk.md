## Overview

公司網站重新構建，並改於第三方平台託管。

## Business Challenge

原本的靜態網站需要提升安全性與整體形象。

## Solution

以 Vue 與 TypeScript 重構網站並加上 RWD，託管於第三方平台，另外開發基於 Markdown 的文章系統。

## Key Features

- 靜態網站加上 RWD
- 使用 Vue + TypeScript 重構網站
- 基於 Markdown 的文章系統
- 部署與維護
