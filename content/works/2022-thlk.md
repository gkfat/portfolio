## Overview

公司網站重新構建，並改於第三方平台託管。

## Business Problem

原本的靜態網站需要提升安全性與整體形象。

## Discovery

- 原靜態網站在安全性與形象上需要更新
- 公司需要能自行更新文章的方式

## Proposed Solution

以 Vue 與 TypeScript 重構網站並加上 RWD，託管於第三方平台，另外開發基於 Markdown 的文章系統。

### Key Features

- 靜態網站加上 RWD
- 使用 Vue + TypeScript 重構網站
- 基於 Markdown 的文章系統
- 部署與維護

## Architecture

- Vue + TypeScript 前端，託管於第三方平台
- 文章以 Markdown 撰寫，建置時產生頁面

## Implementation

- 基於 Markdown 的文章系統，更新文章不需修改程式碼

## Challenges & Trade-offs

- 選擇 Markdown 文章系統而非 CMS：無需維運後台與資料庫，代價是編輯需具備基本 Markdown 能力

## Evaluation & Results

- 尚未量測：目前沒有可追溯的量化數據。
- 已知狀態：網站已上線。
