## Overview

為多家精品品牌開發行銷所需的系統功能。

## Business Challenge

品牌需要透過 Line Liff 與後台，提供桌布收藏、預約與主視覺等行銷互動。

## Solution

拆成桌布櫃、預約與主視覺三個模組，各自由 Server API、後台維護與 Line Liff 前端組成。

## Key Features

- 桌布櫃模組
  - 後台維護桌布系列、Line Liff 收藏桌布系列
- 預約模組
  - 業務端綁定與客戶備註、客戶端註冊與預約
- 主視覺模組
  - 後台維護主視覺、Line Liff 顯示當期主視覺
