## Overview

整合 MES（加工、製造、生產管理）的控制後台，涵蓋從客戶、料件到報價、訂單、採購與生產追蹤的完整管理流程。

## Business Challenge

製造現場的生產狀況需要即時回報到後台，管理端才能掌握每張工單的進度。

## Solution

現場人員掃描 QR Code 即可將資料登錄進後台，管理端即時追蹤工單狀況，把現場生產資訊數位化。

## Key Features

- 帳號＆權限
- 客戶＆供應商管理
- 料件管理
- 報價單＆訂單＆採購單管理
- MES 管理（QR Code 登錄、工單追蹤）
