## Overview

長期合作專案：為長照領域的車行接送開發一套結合 LINE LIFF 與 Admin Web 的派車系統。本專案為其中的管理後台，供車行內勤安排車趟。

## Business Challenge

長照預約派車的需求來自多個管道（乘客自行送單、內勤電話接單），資訊分散，車行難以集中管控與安排車趟。

## Solution

- 乘客透過 LINE LIFF 表單預約，需求單直接串接到後台，消弭資訊落差（見相關專案「派車系統 Line Liff」）
- 後台集中管理所有調度單，包含 LINE LIFF 送單與內勤電話接單

## Key Features

- 系統管理功能
  - 管理派車所需的基本資料：乘客、車輛、司機、地址等
- 調度單管理功能
  - 管理收到的調度單，包含 LINE LIFF 來的乘客送單與內勤電話接單
