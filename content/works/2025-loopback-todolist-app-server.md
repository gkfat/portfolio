## Overview

基於 Loopback4 框架製作的待辦事項 API Server。

## Business Problem

- 練習以 Loopback4 建立具備文件與資料庫的 API Server

## Discovery

- 目標：熟悉 Loopback4 的 Model、Repository、Controller 分層

## Proposed Solution

以 Loopback4 實作 TodoList 的 API Server。

### Key Features

- 待辦事項 API

## Architecture

- Loopback4 + MySQL，Swagger 自動產生 API 文件

## Implementation

- 以 Loopback4 分層實作 TodoList CRUD API

## Challenges & Trade-offs

- 使用框架內建的分層與文件產生，減少樣板程式碼，代價是需遵循框架慣例

## Evaluation & Results

- 尚未量測：目前沒有可追溯的量化數據。
